# Field study protocol — written and spoken digits

Frozen before inference or evaluation. The unit is one independently recorded digit. Test the ten digit identities separately within handwriting and speech and in both directions across modalities. A transfer run uses only the source reference bank and the target holdout. The common label vocabulary permits a direct transfer test.

* Handwriting: select 12 observations per digit from each of the official UCI Optdigits training and writer-independent test partitions. Rank row IDs within each class by SHA-256 with the fixed salt `paper5-field-v1`. Use the published 8 × 8 ink-count grids. Individual writer IDs are unavailable in these files.
* Speech: use Free Spoken Digit Dataset recordings. Sort the six speaker IDs lexically. The first four supply three recordings per digit each and the final two supply six each. Rank file IDs with the same salt. Transform waveforms to 8 × 8 time-frequency measurements. Keep speakers disjoint. There are 120 reference and 120 query observations per modality.
* Embed only the 8 × 8 integer grid in identical row-major text syntax through Cloudflare Workers AI BGE-M3. Exclude labels, speaker, path, split and modality from the payload. This tests a numeric serialization channel. Report an unembedded measurement baseline within each modality.
* Freeze all fits on the reference split. Record raw-grid centroid, embedding centroid, nearest neighbour and native / reference-RMS ambient Gibbs recognition, fixed and reference-energy-adjusted bandwidth (base 0.05). Report fixed-order packing at the source reference median chord and 0.095. Compare class allocation in note equivalents and in the query's natural units (ink pixels or waveform samples).
* Fit a reference-only point-map probe and the half-bit focal prefix (cap seven bits). Compute angular harmonic shares and heat attenuation on the sphere, a reference-fitted harmonic curve residual, fixed-margin concentration and collision nulls (99 draws, 20 trades/row), and signed Hamming/Walsh degree breakdown at temperature 0.75. Check that summing all degrees reconstructs direct class scores. Report degree-only and leave-degree-out recognition.
* Use 999 fixed-seed label permutations, within target speaker for speech and within the test partition for handwriting. Report the one-sided max-over-degrees test and baseline accuracies. These tests address association on the observed holdout. Individual samples from a person may be correlated; two test speakers cannot establish population-level improvement. Compare native and powered predictions on the same observations. Keep the four transfer directions visible, including failures.
* The CI replay consumes archived measured embeddings. It never needs Cloudflare credentials. A new acquisition is a separate provider measurement. Report the model, dimensions, output pooling, row hashes, numeric tolerances and source versions.
