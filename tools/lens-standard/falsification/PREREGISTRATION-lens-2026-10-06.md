## Problem (why this instrument must be falsified before it is trusted)

The powered lens = a self-correcting hierarchy instrument: take a gold droplet render, inject a known aberration, let the instrument estimate the aberration coefficients from the image alone (ink-moment estimators), apply the inverse map, re-render, and re-measure D. If the estimate→inverse→re-measure loop is honest, D returns toward the un-aberrated reference. If the loop silently loses information (re-rasterization, cross-talk, sign flips), D moves and stays moved — and without this corpus the instrument would be trusted on real panels with an unfalsifiable "it corrected" claim.

Falsification criterion (pre-registered, from the ideation one-pager): **D returns monotonically toward the un-aberrated reference across ≥ 3 injected mode types.**

## Construction (pre-registered)

1. **Gold renders**: the pinned edge-standard falsification generators, imported by path from `tools/edge-standard/falsification/gen_v2.py` — `gen_gasket_v2(512, L=384, r=3)` (primary gold, 366 droplets, anchored D), `gen_tri(512)` (19-droplet lattice), `gen_shuffle(512, 42)` (disorder control). No new generator code in this lane; reuse is the point — the gold's D anchors are already pinned downstream.
2. **Mode families** (Lane F implements; the harness only names them):
   - `astigmatism` — anamorphic warp, Zernike Z₂²-like: x→x(1+a), y→y(1−a) around canvas center.
   - `spherical` — radial breathing, Z₄⁰-like: r→r(1+s·f(ρ/R)).
   - `trefoil` — 3-fold shear, Z₃³-like: 3-fold azimuthal displacement.
   Each family carries the **inverse-pair property**: inject(+c) ∘ inject(−c) = identity as continuous maps (exact composition, no fit), so the corrected render differs from the original only by two rasterization round trips plus estimation error. This property is what makes the falsification bands derivable rather than guessed.
3. **Coefficient ladder**: c ∈ {0.05, 0.10, 0.15} plus c = 0 (idempotence rung). Pinned a-priori. A-priori safety arithmetic at the top rung: finest gasket inter-droplet gap at L=384/6 depths is ≈ 12 − 2·3 = 6 px; max local compression at c=0.15 removes ≤ 0.9 px ≪ 6 px, so no droplet merging is predicted at any rung; if N drops anyway, that is a live instance of LF-3/LF-1 recorded honestly, not a ladder change.
4. **Estimation protocol**: primary (gated) = mode-informed single-coefficient fit — the estimator is told WHICH family was injected and returns ĉ for that family only. Secondary (reported, non-gated in v1) = blind 3-coefficient joint fit if the module exposes it; cross-talk is then a measurement, not a failure. Rationale: v1 certifies the correct loop per-family first; blind estimation is the v1.1 candidate.
5. **Re-measure**: full edge-standard-v1 pipeline (threshold → components → contours → box counting, pinned scales [4,6,9,13,20,29,43,64]), D = whole-window fit; same path as the anchored gold runs.

## Gold bands (pre-registered, with a-priori derivations)

| # | Band | Value | Derivation (a-priori) |
|---|---|---|---|
| B1 | Recovery: \|D_corr − D_ref\| ≤ | **0.05** at every rung, every family | Half-pixel rasterization: the hard integer rasterization (inclusive ≤ r² test, no AA) locates each droplet boundary to ±0.5 px ⇒ per-droplet relative radius uncertainty δr/r = 0.5/3 = 0.167. The ink-moment estimator pools over N = 366 droplets with independent rounding ⇒ σ_ĉ ≈ 0.167/√366 ≈ 0.0087; 5σ ≈ 0.044. A residual sub-pixel warp contributes ≤ (0.5 px / 384 px) × the measured L-convergence render-bias spread (0.099 at L=256 → 0.012 at L=384, i.e. 0.11 per 1.5× rescale) ≈ 3e-4 — negligible. B1 is therefore set at 0.05: it dominates the 5σ pooled estimator error with headroom, and is exactly half the measured L-convergence D spread, i.e. the largest re-rasterization shift a sub-pixel-residual re-render could plausibly carry. |
| B2 | Monotonicity: \|D_ab − D_ref\| > \|D_corr − D_ref\| | strict, at every rung, every family | Definitional consequence of the falsification criterion: the injected image must be measurably WORSE than the reference, and the correction must measurably recover. Additionally D_ab must drift monotonically outward from D_ref as \|c\| increases along the ladder; non-monotone D_ab = HARNESS FINDING (the warp is leaving the ink-visible regime), not a re-tunable gate. |
| B3 | Estimation tolerance: max \|ĉ − c\| ≤ | **0.05** per mode, per rung (gated, mode-informed fit) | Same derivation as B1: σ_ĉ ≈ 0.167/√366 ≈ 0.0087 from half-pixel boundary quantization pooled over the gasket; 5σ ≈ 0.044 ≤ 0.05. The coherent-rounding caveat is taken seriously (see LF-5): on a triangular lattice rounding bias is NOT independent, so the √N credit may overstate precision — 0.05 is the pinned tolerance precisely because it is derivable from the pessimistic per-droplet bound under partial coherence, not from the optimistic √N limit. |
| B4 | Idempotence: un-aberrated input | \|ĉ\| ≤ 0.05 per mode AND corrected output **byte-identical** to input | Byte-identity is the only acceptable outcome of inject(0)→correct: the inverse-pair property at c=0 composes to the exact identity map, so any byte difference means the module is not applying the inverse analytically but re-fitting/re-warping something. The \|ĉ\| ≤ 0.05 arm reuses the B3 band. |
| B5 | Structural invariants | component count preserved through the full loop (N_ab and N_corr vs N_ref recorded; a drop flags LF-3/LF-1 as CROP/MERGE and the row is recorded as a non-pass, never silently dropped); non-empty mask on every render (falsification-corpus lesson 3) | Component filters and normalization rules fail silently; only explicit assertions catch it. |
| B6 | r² floor | r² ≥ 0.98 on every reported D fit | House rule, unchanged from edge-standard and spectral preregistrations. |

Gate summary: the falsification criterion passes iff B1 ∧ B2 hold for all 3 families × 3 non-zero rungs on the primary gold (gasket L=384), with B3–B6 holding everywhere. `tri` and `shuffle-s42` carry B3/B4/B5 only (small-N golds; their D anchors are order-vs-disorder discriminators, not recovery targets — B1/B2 are reported for them, non-gated in v1).

## Predicted failure modes (pre-declared)

- **LF-1: re-rasterization destroys fine contours so D never fully recovers.** Each round trip re-quantizes droplet boundaries; the finest gasket level (12 px spacing, r=3 droplets) has the least margin. Pre-declared honest fallback verdict: **"correction reduces but does not eliminate the D shift"** — if B1 fails only at c=0.15 while B2 holds at every rung, the instrument is recorded as a partial corrector with that exact wording. Not fixed by smoothing, supersampling, or tolerance edits post-hoc.
- **LF-2: mode cross-talk** — the astigmatism estimator partially reads spherical (both families move second moments). Prediction: in the blind fit, |ĉ_astig from spherical inject| > 0 measurably. If the gated mode-informed fit also shows \|ĉ − c\| > 0.05 only in mixed directions, record as cross-talk finding; v1.1 candidate = orthogonalized ink moments (Zernike polynomials are orthogonal by construction — the fix is pre-named, never applied mid-run).
- **LF-3: large-coefficient warp pushes droplets off-canvas; cropping changes N.** Most likely under trefoil shear at c=0.15 (corner droplets, ρ ≈ 272 px). If N_corr < N_ref the row is CROP: the loop cannot recover ink it was never shown; verdict recorded honestly, B1 not claimed for that row.
- **LF-4: estimator sign ambiguity** — ink moments are quadratic forms; a warp and its negative can produce the same moment signature for symmetric golds (the gasket has 3-fold symmetry, which a trefoil could alias against). Prediction: sign ambiguity fires on the gasket gold under trefoil before it fires on tri/shuffle. Detection: run the estimate on inject(+c) and inject(−c); if ĉ has the same sign for both, the estimator is sign-blind and the loop will double the aberration instead of removing it — HARNESS FINDING, recorded as such.
- **LF-5 (added by this lane): lattice-coherent rounding bias.** The B1/B3 derivation takes the √N credit over 366 droplets, but the gasket's droplets sit on a coherent triangular lattice — rounding errors are correlated, not independent, so the true σ_ĉ may exceed 0.0087. Pre-declared consequence: if B3 fails with a coherent-sign bias (all ĉ biased the same direction), the honest verdict is "the estimator precision band was derived under an independence assumption the lattice violates" and the fix is a NEW preregistered amendment (e.g. jitter-augmented gold), never a silent tolerance change.
