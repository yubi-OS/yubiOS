# skill-check — frozen content check, deterministic fixer, and wayfinder cycle driver

Written for the 2026-09-17 skills round (`refs/wayfinder-skills-round1-2026-09-17.md`) and the follow-up sweep (`refs/skills-check-sweep-2026-09-17.md`). Process rules: `tools/point-map/AGENT.md` → "Lessons learned".

- `skillcheck.sh <file> [<repo-root>]` — independent content check, exit text `TASK CHECK: PASS|FAIL`. C1 mojibake/replacement bytes; C2 duplicate `##` headings; C3 "TBD per file context / TODO: refine" placeholders; C4 SKILL.md frontmatter per the skill-format spec (closed block, `name` `^[a-z0-9-]{1,64}$`, `description` 1..1024 chars, no `<`/`>`); C5 template capability paragraphs; C6 unresolved local links. Python 3 stdlib only. Freeze it before looking at any rung.
- `fixer.py <in> <out>` — deterministic repairs for exactly those classes (base64-committed body decode; mojibake; description overflow moved verbatim to an "Extended description" section; angle brackets; placeholder sections dropped; template paragraphs → dated coverage note; duplicate sections merged into the first, keeping all non-duplicate text). Never invents content. If the result still fails the check, revert and record `declined`.
- `wayfinder-cycle.py` — one wayfinder cycle against a live baseline: top untouched CHANGE rung (ADD rungs declined and recorded once per sector; exemplar fallback on exhaustion) → pending ledger row → check → fixer → check → single-file commit on the held branch → after-map on the chained `baseline_id` with the exact baseline name set → `kept` verdict row. Environment: `WAYFINDER_CORPUS_ROOT` (checkout containing `paths.txt`), `WAYFINDER_STATE` (state JSON with `branch`, `branch_sha`, `latest`, `touched`, `declined_adds`, `cycles`); `baseline_names.json` next to the state file. GitHub calls need the repo credential in the environment's proxy.

Sweep recipe (no geometry): run `skillcheck.sh` over every file, apply `fixer.py` to the failures, re-check, commit the passing set as one PR stacked on the round branch.
